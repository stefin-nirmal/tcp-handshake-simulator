Sequence & Acknowledgment Arithmetic

RFC 793 Math
Client Initial Sequence Number (ISN)
Seq = 1000

Generated dynamically via 32-bit PRNG to prevent packet collisions and replay attacks.

Server Initial Sequence Number (ISN)
Seq = 5000

Generated independently by server OS for the reverse byte stream channel.

Step Packet Sender → Receiver Sequence (Seq) Acknowledgment (Ack) Calculation Rationale
1 SYN Client → Server 1000 - Client initiates connection with random starting byte (ISN).
2 SYN-ACK Server → Client 5000 1001 Ack = Client ISN + 1 (Acknowledges client SYN byte).
3 ACK Client → Server 1001 5001 Ack = Server ISN + 1 (Acknowledges server SYN byte). Connection fully established!
